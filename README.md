# Phân tích dữ liệu bán hàng bằng Python

Dự án cá nhân cho nội dung **5.5 - Phân tích dữ liệu cơ bản với NumPy, Pandas và Matplotlib**.

## Nội dung
- Đọc và làm sạch dữ liệu bán hàng từ CSV.
- Tính tổng doanh thu, tổng số lượng và doanh thu trung bình mỗi đơn.
- Phân tích doanh thu theo tháng.
- Phân tích doanh thu và số lượng theo sản phẩm.
- Tạo biểu đồ bằng Matplotlib và lưu vào thư mục `images`.

## Công nghệ
- Python
- NumPy
- Pandas
- Matplotlib

## Cách chạy
1. Đặt `sales_analysis.py` và `sales_data.csv` trong cùng thư mục.
2. Cài thư viện: `pip install numpy pandas matplotlib`
3. Chạy: `python sales_analysis.py`
4. Biểu đồ sẽ được tạo tự động trong thư mục `images`.
